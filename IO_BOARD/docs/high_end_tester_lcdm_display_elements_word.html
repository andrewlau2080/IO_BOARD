高档测试机 LCDM 显示元素表

本文件是第一份 Word 规格表，只定义 LCDM 屏幕上要显示的全部元素，包括固定元素、会变化的元素、K1-K4 按键元素、以及不同测试状态下动态元素显示什么。坐标和通讯逻辑分别由后续两个文件定义。

1. 页面

页面 ID 页面名称 用途 显示规则
0 tester_main 高档测试机主界面 第一版只使用这一页；上电后由 MCU 全屏绘制界面，不依赖屏内旧项目控件。

2. 固定显示元素

元素 ID 元素名称 类型 固定显示内容 用途 刷新方式
screen_bg 全屏背景 色块 白色背景 覆盖屏幕原内容，防止露出旧控件。 全屏绘制时刷新。
title_bar 标题栏背景 色块 深蓝色横条 页面顶部标题区。 全屏绘制时刷新。
title_text 标题文字 文本 WIRE TESTER LCDM 显示设备/界面名称。 全屏绘制时刷新。
role_text 角色文字 文本 TESTER 显示当前为测试机界面。 全屏绘制时刷新。
status_panel 主状态背景 色块 浅色背景 承载状态文字和主显示文字。 全屏绘制时刷新。
key_band 按键带背景 色块 K1-K4 四段按键背景 承载四个触摸按键。 全屏绘制时刷新；按键按下/松开时局部刷新对应按键。
ledm_panel LEDM 兼容显示背景 色块 白色区域 显示原 LEDM/TM1637 的 6 字符兼容内容。 全屏绘制时刷新；内容变化时先清背景再写文字。
detail_panel 详情背景 色块 白色区域 显示点位、数量、故障原因或测试进度。 全屏绘制时刷新；详情变化时局部刷新。
sub_panel 辅助提示背景 色块 白色区域 显示操作提示或触摸调试信息。 全屏绘制时刷新；提示变化时局部刷新。

3. 会变化的显示元素

元素 ID 元素名称 类型 可能显示内容 数据来源 变化条件
state_text 状态文字 文本 READY / SELF / AUTO / LEARN / PASS / NG 固件状态机。 待机、自检、自动测试、学习、PASS、NG 等状态切换时变化。
main_text 主显示文字 文本 AUTO TEST / SELF TEST / LEARN MODE / PASS / NG 固件状态机。 状态切换时变化，用于给操作者看当前主状态。
ledm_text LEDM 兼容显示 文本 AUTO / A01b01 / PASS / 001002 / LEArn 原 LEDM 显示模型。 测试点位、测试结果、学习流程或状态变化时变化。
detail_text 详情文字 文本 PROFILE DB50 / OUT001 IN002 / OK 092/092 / TOTAL 092 OK 测试流程和点位资料。 测试进度、当前 OUT/IN 点位、故障详情或结果统计变化时变化。
sub_text 辅助提示文字 文本 K1 SELF/LEARN K2 AUTO K3 RESET K4 OK 当前状态提示。 不同状态下显示对应操作提示。
touch_debug_text 触摸调试文字 文本 T 060,140 -> K1 DOWN LCDM 触摸解析结果。 调试阶段收到触摸坐标、组件触摸或 ASCII 命令时，可临时覆盖辅助提示文字。

4. K1-K4 按键显示元素

元素 ID 按键 上排显示 下排显示 显示状态 动作含义 固件内部键值
key_k1 K1 K1 SELF/LEARN 普通：深灰背景；按下：蓝色背景。 短按自检；长按约 3 秒进入学习。 FIRST_GEN_KEY_SET
key_k2 K2 K2 AUTO 普通：深灰背景；按下：蓝色背景。 自动测试。 FIRST_GEN_KEY_CLEAR
key_k3 K3 K3 RESET 普通：深灰背景；按下：蓝色背景。 复位到待机，测试重来。 FIRST_GEN_KEY_PLUS
key_k4 K4 K4 OK/SAVE 普通：深灰背景；按下：蓝色背景。 确认/保存；调试阶段可切 PASS。 FIRST_GEN_KEY_MINUS

6. 显示实现边界

项目 规则
显示来源 所有可见内容都必须来自本文件的元素表。
动态变化 动态元素只由固件状态机、测试流程、LEDM 兼容显示模型和触摸调试结果更新。
旧控件 高档测试机界面不显示屏内旧项目控件；如旧控件露出，属于错误状态，应全屏重绘或修改屏端基础页为空白。
