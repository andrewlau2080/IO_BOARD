# 高档测试机 LCDM 元素坐标表

本文件定义高档测试机 LCDM 页面上“画在哪里、点哪里”。元素 ID 必须与
`high_end_tester_lcdm_ui_elements.md` 保持一致。

## 屏幕坐标约定

| 项目 | 值 |
|---|---:|
| 屏幕方向 | 横屏 |
| 屏幕宽度 | `480` |
| 屏幕高度 | `272` |
| X 有效范围 | `0..479` |
| Y 有效范围 | `0..271` |
| 坐标原点 | 左上角 |
| 单位 | 像素 |

## 非按键区域

| 区域 | X 范围 | Y 范围 | 处理 |
|---|---|---|---|
| 标题和状态区 | `0..479` | `0..111` | 不触发动作，只可记录调试坐标 |
| 按键下方内容区 | `0..479` | `170..271` | 不触发动作，只可记录调试坐标 |
| 屏外异常坐标 | 其它 | 其它 | 丢弃或显示调试信息 |

## 坐标方向兼容

主规则只认横屏坐标。若实测 LCDM 回包方向不一致，解析顺序固定如下，不能随意改。

| 顺序 | 输入 | 判断 | 处理 |
|---:|---|---|---|
| 1 | `(x,y)` | 可直接命中 K1-K4 | 使用原坐标 |
| 2 | `(x,y)` | `x < 272 && y < 480` 且 `(y,x)` 可命中 K1-K4 | 使用交换坐标 |
| 3 | 其它 | 无法命中 | 显示调试信息，不执行业务动作 |
