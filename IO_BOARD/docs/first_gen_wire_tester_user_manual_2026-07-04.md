# 一代线束测试机使用说明书

版本日期：2026-07-04  
适用固件：`FIRST_GEN_4051_LOCAL` 当前测试版本  
适用显示：6位 LEDM / TM1637 显示按键模块  

## 1. 设备功能

本设备用于线束导通测试。设备会根据已学习保存的标准线束资料，实时扫描当前线束连接状态，并判断：

| 状态 | 含义 |
|---|---|
| PASS | 当前线束与已学习标准一致 |
| NG | 当前线束存在断线、短路、多接、错接等不良 |
| 数字线号 | 显示不良对应 OUT/IN 位置 |
| Printd | 打印流程完成 |

当前版本扫描范围为 48 组输出、48 组输入。

## 2. 按键定义

LEDM 模块上的 4 个按键按当前程序定义如下：

| 按键 | 功能 |
|---|---|
| K1 | 短按：自检显示；长按约 3 秒：进入学习预览 |
| K2 | 自动测试 / 进入实时扫描 |
| K3 | 复位 / 重来 |
| K4 | 学习确认保存 |

外部打印触发键：

| 信号 | 功能 |
|---|---|
| PC7 | PASS 状态下按下超过 20ms 后触发打印 |

PC7 为输入上拉，按下为低电平有效。

## 3. 开机显示

开机后显示 `WIRE TESTER` 滚动字样。

按任意 LEDM 按键后停止滚动，进入待机状态：

| 显示 | 含义 |
|---|---|
| AUTO-T | 已有学习资料，可进入自动测试 |
| LEArn | 没有有效学习资料，需要先学习标准线束 |

## 4. 学习标准线束

学习用于保存一条合格样品线束作为后续判断标准。

操作步骤：

1. 接入确认合格的标准线束。
2. 长按 K1 约 3 秒。
3. 设备开始学习扫描。
4. 学习预览完成后，显示会在两屏之间交替：
   - `004004`：有效 OUT 数 / 有效 IN 数。
   - `tot-08`：总点数。
5. 确认无误后按 K4 保存。
6. 保存成功后，`tot-xx` 快闪两次，然后显示 `SAUEd`。

注意：如果未接线或学习结果异常，会显示 `Erxxxx` 错误代码，不会保存。

### TOT 计算规则

`TOT` 不是矩阵导通组合数，而是：

```text
TOT = 有效 OUT 数 + 有效 IN 数
```

示例：

```text
OUT1-IN1
OUT1-IN2
OUT2 空
OUT3-IN3
OUT4-IN4
```

计算结果：

| 项目 | 数量 |
|---|---:|
| 有效 OUT | 3：OUT1、OUT3、OUT4 |
| 有效 IN | 4：IN1、IN2、IN3、IN4 |
| TOT | 7 |

对应显示为：

| 显示 | 含义 |
|---|---|
| 003004 | 3 个有效 OUT，4 个有效 IN |
| tot-07 | 总点数 7 |

一拖多时，输出端头只算 1 个 OUT，分线端每个 IN 单独计数。

## 5. 自动测试 / 实时扫描

按 K2 进入自动测试。

扫描过程中不显示每个通道号，以免影响扫描速度。当前扫描动画为两个横线一组跳动：

| 显示 | 含义 |
|---|---|
| `--    ` | 正在扫描 |
| `  --  ` | 正在扫描 |
| `    --` | 正在扫描 |

设备会持续实时扫描，不需要等固定延时。

## 6. PASS 状态

如果完整一轮扫描全部正常，显示：

| 显示 | 含义 |
|---|---|
| PASS | 当前线束合格 |

PASS 状态下设备仍会继续扫描。如果后续出现断线、短路、多接、错接，会立即转为 NG。

## 7. NG 状态

检测到不良时，显示会在 `NG` 和不良线号之间轮流切换。

示例：

| 显示 | 含义 |
|---|---|
| NG | 当前线束不良 |
| 001002 | OUT001 对应 IN002 存在不良 |

不良包括断线、短路、多接、错接等。当前显示的是程序扫描到的一个不良点。修复线束后，设备继续实时扫描；下一整轮全部正常后会恢复为 `PASS`。

## 8. 打印操作

打印只允许在 PASS 状态下触发。

操作条件：

1. 显示为 `PASS`。
2. 按下外部 PC7 打印触发键超过 20ms。
3. 设备发送红外打印信号。
4. 打印完成后显示 `Printd`。

如果当前为 `NG`，按 PC7 不会打印。

## 9. 复位 / 重来

按 K3 可复位当前操作并回到待机状态。

复位后：

| 条件 | 显示 |
|---|---|
| 已有学习资料 | AUTO-T |
| 没有学习资料 | LEArn |

## 10. 自检显示

短按 K1 进入显示自检。

自检会依次显示测试序号，完成后显示：

| 显示 | 含义 |
|---|---|
| SELF-O | 自检完成 |

## 11. 常见显示说明

| 显示 | 说明 |
|---|---|
| WIRE TESTER | 开机滚动提示 |
| AUTO-T | 自动测试待机 |
| LEArn | 需要学习 |
| PASS | 测试合格 |
| NG | 测试不良 |
| 001002 | OUT001 / IN002 对应不良点 |
| tot-04 | 学习到 4 个连接 |
| 004004 | 学习结果：4 个有效 OUT，4 个有效 IN |
| SAUEd | 学习保存成功 |
| Printd | 已完成打印 |
| Er0000 / Erxxxx | 错误代码 |

## 12. 使用注意事项

1. 第一次使用或更换产品线束规格后，必须先学习标准线束。
2. 学习时必须接入确认合格的样品线束。
3. 自动测试时设备会持续扫描，显示通道号已取消，以保证扫描速度。
4. 只有 `PASS` 状态下按 PC7 才会打印。
5. 如果显示 `NG`，应根据轮显线号检查对应线束。
6. PC7 是低电平有效触发输入，按键接地触发。
7. 学习完成后，K4 保存、K3 取消、K2 自动测试都会等待所有按键完全释放并稳定约 200ms，避免按键释放抖动误触发其它功能。
